## 개발 과정에서 잡은 결함

교차검증 체계와 자체 점검 도구가 세 번 값을 했다.

1. **런타임 TF-IDF 정규화 오류** — 학습은 블록별로, 실행은 합쳐서 한 번 정규화하고
   있었다. 예측이 최대 0.55 어긋났고 그대로 제출하면 세 등급 모두 예산 초과로
   최종 0점이었다. 어긋난 예측이 우연히 예산을 적게 쓰는 방향이라 공식 self-check를
   통과해 드러나지 않았다.
2. **입력 순서 의존** — 같은 프롬프트가 배치에 있으면 힙의 입력 인덱스가 최종 판단
   기준이 되어, 동일 프롬프트 100문항에서 premium 16건이 어긋났다. 내용 해시로
   그룹을 묶어 통째로 승격하도록 고쳤다.
3. **잔차 보정 오류** — 감사 지적을 과하게 적용해 보정 전체를 full-fit 예측 기준으로
   바꿨더니, 트리 모델의 in-sample 잔차가 거의 0이라 비용을 크게 과소평가했다.
   총액 보정은 full-fit, 잔차 상향은 OOF로 분리했다.

그밖에 예산 가드 포화(안전계수가 탐색 상한 1.4에 붙어 사실상 무력화), 비용 보정
편향(추론 모델이 19% 싸 보임), 고립 서로게이트 문자에서의 등급 실행 실패,
읽기 전용 루트에서 매 실행 2.4초를 버리던 재컴파일을 함께 고쳤다.

## 시도했으나 채택하지 않은 것

측정 결과를 따랐다. 모두 코드 주석과 보고서에 근거를 남겼다.

| 시도 | 결과 | 판단 |
|---|---|---|
| 부스팅 트리 토큰 예측 | 상관 0.37→0.65, Dev 0.688(최고) | **기각** — 교차검증에서 어떤 마진으로도 premium 예산 초과 |
| 다국어 문장 임베딩 | d2 상관 0.425→0.372/0.391 | **기각** — 오히려 나쁘고 이미지 170MB·시간 30~60초 증가 |
| ridge 계수 앙상블 | +0.001 | **기각** — 선형 모델끼리는 예측 다양성이 없음 |
| 문항별 예측 비용 상한 | 효과 없음 | **기각** — 예측이 작고 실제가 큰 문항을 못 거름 |
| 분위수 회귀 비용 | CV 0.61→0.28~0.49 | **기각** — 역효과 |

도달 가능 상한 분석: 전부 경량 0.605 / 비용만 정확 0.683 / K1 이득 완전정보 0.725 /
완전정보 오라클 0.792. 남은 격차의 상당 부분은 점수가 생성 2~4회 평균이라 생기는
예측 불가능한 노이즈다.
